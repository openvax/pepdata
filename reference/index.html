    pmbec ¶

    read_pmbec_coefficients ¶

    read_pmbec_coefficients(key_type='row', verbose=True, filename=join(MATRIX_DIR, 'pmbec.mat'))

    Parameters:

    • filename (str, default: join(MATRIX_DIR, 'pmbec.mat') ) –

      Location of PMBEC coefficient matrix

    • key_type (str, default: 'row' ) –

      'row' : every key is a single amino acid, which maps to a dictionary for that row 'pair' : every key is a tuple of amino acids 'pair_string' : every key is a string of two amino acid characters

    • verbose (bool, default: True ) –

      Print rows of matrix as we read them

    mhc ¶

    load_dataframe ¶

    load_dataframe(mhc_class=None, hla=None, exclude_hla=None, human_only=False, peptide_length=None, assay_method=None, only_standard_amino_acids=True, warn_bad_lines=True, nrows=None)

    Load IEDB MHC data without aggregating multiple entries for the same epitope

    Parameters:

    • mhc_class (int | None, default: None ) –

      Restrict to MHC Class I or Class II (or None for neither)

    • hla (str | None, default: None ) –

      Restrict results to specific HLA type used in assay (regex pattern)

    • exclude_hla (str | None, default: None ) –

      Regex pattern to exclude certain HLA types

    • human_only (bool, default: False ) –

      Restrict to human samples (default False)

    • peptide_length (int | None, default: None ) –

      Restrict epitopes to amino acid strings of given length

    • assay_method (str | None, default: None ) –

      Limit to assay methods which contain the given string

    • only_standard_amino_acids (bool, default: True ) –

      Drop sequences which use non-standard amino acids, anything outside the core 20, such as X or U (default = True)

    • warn_bad_lines (bool, default: True ) –

      The full MHC ligand dataset seems to contain several dozen lines with too many fields. This currently results in a lot of warning messages from Pandas, which you can turn off with this option (default = True)

    • nrows (int | None, default: None ) –

      Don't load the full IEDB dataset but instead read only the first nrows

    load_dataframe ¶

    load_dataframe(mhc_class=None, hla=None, exclude_hla=None, human_only=False, peptide_length=None, assay_method=None, only_standard_amino_acids=True, reduced_alphabet=None, nrows=None)

    Load IEDB T-cell data without aggregating multiple entries for same epitope

    Parameters:

    • mhc_class (str | None, default: None ) –

      Restrict to MHC Class I or Class II (or None for neither)

    • hla (str | None, default: None ) –

      Restrict results to specific MHC used in assay

    • exclude_hla (str | None, default: None ) –

      Exclude certain MHC allele patterns

    • human_only (bool, default: False ) –

      Restrict to human samples (default False)

    • peptide_length (int | None, default: None ) –

      Restrict epitopes to amino acid strings of given length

    • assay_method (str | None, default: None ) –

      Only collect results with assay methods containing the given string

    • only_standard_amino_acids (bool, default: True ) –

      Drop sequences which use non-standard amino acids, anything outside the core 20, such as X or U (default = True)

    • reduced_alphabet (dict | None, default: None ) –

      Remap amino acid letters to some other alphabet

    • nrows (int | None, default: None ) –

      Don't load the full IEDB dataset but instead read only the first nrows
